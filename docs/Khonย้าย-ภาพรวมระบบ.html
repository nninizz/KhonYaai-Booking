#กฎรับผิดชอบตรวจที่ไหน
1จ่ายมัดจำ 30% ของค่าบริการเมื่อจองรถ ปัดเป็นบาท (เศษ .50 ขึ้นไปปัดขึ้น) ส่วนที่เหลือ = ค่าบริการ − มัดจำ③ คำนวณ · ④ เก็บเงินbackend
2เวลานัดต้องห่างจากตอนกดจอง ≥ 4 ชั่วโมง (ให้ระบบมีเวลาหาคนขับในละแวกใกล้เคียง)③frontend ปิดตัวเลือกเวลา + backend ตรวจซ้ำ
3ยกเลิก ≥ 2 ชม. ก่อนเวลานัด → คืนมัดจำเต็มจำนวนภายใน 2 ชม. · มากกว่า 45 นาที แต่น้อยกว่า 2 ชม. → ริบมัดจำเข้า platform (ต้องมี popup เตือนให้ยืนยันก่อน) · เหลือ ≤ 45 นาที (รวม 45 นาทีพอดี) → ยกเลิกไม่ได้⑥ ตัดสิน · ④ คืนเงิน/ริบเงินbackend (popup ฝั่ง frontend)
4การจองต้องระบุ วัน เวลา สถานที่รับ–ส่ง และ ขนาดสิ่งของ เล็ก / กลาง / ใหญ่ (ขนาดยังไม่มีผลกับราคา)③frontend + backend
5ค่าบริการ = ระยะทาง (กม.) × 10 บาท · ผู้จองกรอกต้นทางและปลายทาง ระบบคำนวณระยะทางจากพิกัด GPS ให้เอง (ปัดระยะทางเป็นทศนิยม 1 ตำแหน่ง ราคาจึงเป็นบาทเต็มเสมอ)③backend (mock พิกัด)
6จ่ายมัดจำผ่าน QR พร้อมเพย์ หรือ บัตรเครดิต ส่วนที่เหลือ 70% จ่ายตรงกับคนขับหลังจบงาน (นอกระบบ)④backend (mock)
7สถานะติดตาม: จองสำเร็จ (จ่ายมัดจำแล้ว) → กำลังหาคนขับ → คนขับรับงาน → จบงาน (คนขับเป็นคนกดจบงาน ใช้ mock แทน)⑤ แสดง · mock เลื่อนbackend

9Mock ชำระเงิน: บัตรเลขลงท้าย 0000 = ล้มเหลว นอกนั้นสำเร็จ · QR มีปุ่ม “จำลองว่าจ่ายแล้ว”④backend (mock)

def calc_distance_km(lat1, lng1, lat2, lng2):   # กฎข้อ 5 — ระยะทางจากพิกัด GPS
    from math import radians, sin, cos, asin, sqrt
    dlat, dlng = radians(lat2 - lat1), radians(lng2 - lng1)
    a = sin(dlat/2)**2 + cos(radians(lat1)) * cos(radians(lat2)) * sin(dlng/2)**2
    return round(6371 * 2 * asin(sqrt(a)), 1)    # เส้นตรง ปัดทศนิยม 1 ตำแหน่ง

def calc_price(distance_km):                      # กฎข้อ 1, 5
    total = round(distance_km * PRICE_PER_KM)
    deposit = (total * DEPOSIT_PERCENT + 50) // 100   # ปัดเป็นบาท (.50 ปัดขึ้น) ใช้เลขจำนวนเต็มกันปัญหาทศนิยม float
    return {"total_price": total, "deposit_amount": deposit, "remaining_amount": total - deposit}
