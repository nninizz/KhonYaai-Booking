## 1. Intent

ร่างนี้ระบุเงื่อนไขการจอง การชำระมัดจำ ค่าขนย้าย สถานะงาน และการยกเลิกตามกฎชุดใหม่ที่กลุ่มให้
Cancellation แบ่งตามเวลาที่เหลือก่อนนัดหมาย โดยกำหนดผลต่อการยกเลิกและเงินมัดจำตาม Decision Table ใน `rules.md`
ช่วงเวลาที่เหลือ >= 120 นาที, >= 45 นาทีและ < 120 นาที, และ < 45 นาที กำหนดผลตาม Decision Table ใน `rules.md`; กรณี 45 นาทีรวมอยู่ในช่วง >= 45 นาทีและ < 120 นาทีตามคำยืนยันจากกลุ่ม.

## 2. Scope และ Non-goals

**In (Draft):**
- การชำระมัดจำ 50% เมื่อจองรถ และการจองล่วงหน้าอย่างน้อย 4 ชั่วโมง
- ข้อมูลที่ต้องระบุในการจอง: วัน เวลา สถานที่ และขนาดสิ่งของ เล็ก / กลาง / ใหญ่
- ค่าขนย้าย 4 บาทต่อกิโลเมตร
- การชำระมัดจำด้วย PromptPay QR หรือบัตรเครดิต และชำระส่วนที่เหลือให้คนขับโดยตรงหลังจบงาน
- เงื่อนไขยกเลิกตามเวลาที่เหลือก่อนนัดหมาย รวมกรณีเตือนก่อนยืนยัน กรณียกเลิกไม่ได้ และการคืนมัดจำตามกฎใหม่
- สถานะงานตามลำดับที่กลุ่มให้: จองสำเร็จหลังชำระมัดจำ → กำลังหาคนขับ → คนขับรับงาน → จบงาน

**Non-goals / ขอบเขตที่ยังไม่กำหนด (ไม่ใช่ข้อสรุปให้ตัดออก):**
- วิธี/ช่องทางและผู้ดำเนินการคืนเงินมัดจำยังไม่ระบุ
- ระบบภายนอก, API, database schema, วิธีหาระยะทาง และวิธีคิดฐาน 50% ยังไม่กำหนด
- การแจ้งเตือนผู้ให้บริการจากร่างเดิมไม่ได้ยืนยันซ้ำในกฎใหม่ จึงยังไม่ถือเป็นกฎปัจจุบัน
- การยกเลิกโดยคนขับจากเหตุสุดวิสัยและการคืนเงิน 7–15 วันเป็นข้อมูลเดิมที่เก็บใน Decision Log; ไม่ใช้เป็นกฎปัจจุบัน

### Cross-feature Dependencies (ไม่แก้เอกสารฟีเจอร์อื่น)

| Feature | ความเชื่อมโยงที่ต้องประสาน |
|---|---|
| Booking — `specs/003-booking/` | ข้อมูลวัน เวลา สถานที่ ขนาดสิ่งของ, การจองล่วงหน้าอย่างน้อย 4 ชั่วโมง, การชำระมัดจำ และสถานะเริ่มต้นหลังชำระ |
| Payment — `specs/004-payment/` | มัดจำ 50%, PromptPay QR/บัตรเครดิต, การคืนมัดจำตามเงื่อนไขยกเลิก และการจ่ายส่วนที่เหลือให้คนขับโดยตรงหลังจบงาน |
| Tracking — `specs/005-tracking/` | ลำดับสถานะงาน: จองสำเร็จ → กำลังหาคนขับ → คนขับรับงาน → จบงาน |

ตารางนี้เป็นรายการ dependency สำหรับการประสานงานเท่านั้น ไม่ได้แก้หรือกำหนดข้อกำหนดแทนฟีเจอร์เหล่านั้น.

## 5. Behaviour

กฎปัจจุบันอยู่ใน `rules.md` และเชื่อมกับ `feature.feature` ดังนี้:

- การยกเลิก: `BR-CAN-DRAFT-09` แบ่งช่วงเวลาเป็น >= 120 นาที, >= 45 นาทีและ < 120 นาที (รวม 45 นาทีพอดี), และ < 45 นาที
- การคืนมัดจำ: เมื่อเหลือเวลา >= 2 ชั่วโมง คืนเต็มจำนวนภายใน 2 ชั่วโมง; จุดเริ่มนับและช่องทางคืนเงินรอยืนยัน Q-06-11
- ช่วง >= 45 นาทีและ < 120 นาที ยกเลิกได้แต่ไม่คืนมัดจำ มัดจำเป็นของ Platform และต้องแสดงคำเตือนก่อนลูกค้ายืนยัน
- ช่วง < 45 นาที ยกเลิกไม่ได้
- การจอง การชำระ และสถานะงานเป็น Cross-feature Dependencies ตามตารางในส่วน 2

## 8. Constraints

- สถานะเอกสารและ IDs ใหม่ทั้งหมดเป็น Draft; ยังไม่มี Baseline ที่ยืนยันแล้ว
- ใช้ตัวเลขตามกฎใหม่โดยไม่เปลี่ยน: มัดจำ 50%, จองล่วงหน้าอย่างน้อย 4 ชั่วโมง, 2 ชั่วโมง, 45 นาที, 4 บาทต่อกิโลเมตร และคืนมัดจำภายใน 2 ชั่วโมง
- Q-06-10 ปิดแล้วตามคำยืนยันจากกลุ่ม: เวลา 45 นาทีพอดียกเลิกได้หลังเตือนและยืนยัน ไม่คืนมัดจำ และมัดจำเป็นของ Platform
- ไม่กำหนดวิธีคำนวณฐานมัดจำ วิธีหาระยะทาง ช่องทางคืนเงิน API หรือ Database Schema โดยไม่มีข้อมูล
- ข้อความเดิม 7–15 วันและข้อกำหนดคนขับยกเลิกไม่ใช่กฎปัจจุบัน; เก็บใน Decision Log และ Rules เพื่อ traceability
- ไม่พบ `specs/000-shared/constraints.md`; ข้อจำกัดกลางและเทคโนโลยียังยืนยันไม่ได้
