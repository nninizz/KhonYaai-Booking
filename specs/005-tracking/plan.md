## 1. สรุปแนวทาง

ฟีเจอร์นี้ให้ลูกค้าเห็นตำแหน่งคนขับบนแผนที่ Google Maps ตั้งแต่คนขับรับงานจนรถอยู่ในรัศมี 5 เมตรจากปลายทางที่ลูกค้าปักหมุด (D-05-12, AS-02) ผู้ใช้คือลูกค้า (ดูตำแหน่ง) และคนขับ (ส่งพิกัดทุก 15 วินาที และกดยืนยันส่งงาน)
แนวทางคือ backend ภาษา Python รับและเก็บพิกัดล่าสุดของงาน ตรวจรัศมี ลบพิกัดตามกติกาที่สเปกกำหนด และให้ frontend ภาษา React.js อ่านค่าล่าสุดทุก 15 วินาทีเพื่อแสดงบน Google Maps
ทุกข้อในแผนนี้อ้างกลับไปยัง ID ในสเปกได้ (REQ-IF-001, REQ-QA-001, D-05-xx, AS-xx, Q-xx)

| Entity | ฟิลด์หลัก | รองรับ | หมายเหตุ |

| TrackingSession (งานที่ติดตาม) | job_id, driver_id, destination_lat, destination_lng, status (active, arrived, cancelled, closed), started_at, arrived_at, closed_at | REQ-IF-001, REQ-QA-001, D-05-06, D-05-12, AS-02, AS-05 | destination เป็น PII (D-05-13, Q-17) ลบพร้อมพิกัดคนขับตามกติกาการลบ |

ข้อจำกัด: ไม่มีฟิลด์เลขบัตรประชาชน ที่อยู่บ้านของคนขับ หรือเบอร์โทร ใน entity ทั้งสองตัวนี้ (ไม่มี Constraint กลางให้ยืนยันเรื่องนี้ ทีมตรวจเอง)

## 4. API และหน้าจอ

API (backend, Python):
- `POST /api/tracking/{job_id}/start` เรียกเมื่อคนขับรับงาน สร้าง TrackingSession สถานะ active (AS-02, REQ-IF-001)
- `POST /api/tracking/{job_id}/points` คนขับส่งพิกัด input: lat, lng, accuracy_m, recorded_at ตรวจรัศมี 5 เมตรและเปลี่ยนสถานะเป็น arrived เมื่อเข้าเขต (REQ-QA-001, REQ-IF-001, D-05-12, AS-08)
- `GET /api/tracking/{job_id}/latest` ลูกค้าอ่านทุก 15 วินาที output: lat, lng, recorded_at, is_stale (เกิน 60 วินาที, AS-07), status, และ unavailable เมื่อ Google Maps หรือ GPS ใช้ไม่ได้ (AS-06) ไม่ส่งรายละเอียดทางเทคนิค (REQ-QA-001, REQ-IF-001, D-05-14)
- `POST /api/tracking/{job_id}/confirm` คนขับกดยืนยันส่งงาน ลบ LocationPoint ทั้งงาน ไม่บล็อกถ้าอยู่นอกรัศมี (Q-07, D-05-07, AS-03)
- `POST /api/tracking/{job_id}/cancel` ยกเลิก หยุดแสดงและลบทันที (AS-05, D-05-17)
- งานตั้งเวลาภายใน (ไม่ใช่ endpoint) ลบพิกัดที่เกิน 24 ชั่วโมงหลัง arrived_at (AS-04, D-05-21)

หน้าจอ:
- `CustomerTrackingPage` แผนที่ Google Maps แสดงตำแหน่งล่าสุด ป้ายไม่เป็นปัจจุบัน ข้อความ "ตำแหน่งไม่พร้อมใช้งาน" และเวลาตำแหน่งล่าสุด (REQ-IF-001, REQ-QA-001, AS-06, AS-07, D-05-14) ไม่มี mockup ทีมออกแบบเอง
- `DriverTrackingPage` ส่งพิกัดทุก 15 วินาที และปุ่มยืนยันส่งงาน (REQ-QA-001, Q-07) ไม่มี mockup ทีมออกแบบเอง
- ไม่มี UI-xx ในสเปก เพราะส่วน 12 ของ spec ระบุว่ายังไม่มี
